# 第一版：视频总结与自动日报

2026-10-21 用户明确收敛的产品范围，优先于旧里程碑规划。

1. 设置关键词、每轮视频数量和定时间隔，自动搜索 B站、选取相关视频、获取字幕。
2. 一个视频只对应一条信息动态；动态就是整份视频/资料的总结，不再按主张或实体拆动态。
3. 每轮所有视频成功或明确失败后，汇总本轮动态、更新相关实体，再更新当日日报。
4. 定期检查已登录 B站账号收到的 @，将对应视频送入同一流程。
5. 关键词、手动链接和 @ 共用视频身份去重；已成功总结的视频直接复用，失败允许重试。
6. 主界面只保留动态、自动任务、实体、日报和必要设置；主题、事实核查、证据分档等高级入口暂时隐藏，历史数据保留。

实现约定：实体是产品、工具、人物等对象的累积简介，保留来源关联；日报按工作区日期累计各轮汇总。长字幕应分段覆盖，不把截断后的前半段伪称完整总结；无字幕、登录失效、预算不足必须显示具体状态。@ 只读取通知并处理视频，不自动发送评论或私信。**实体只在被视频实质讨论（反复出现或作为核心介绍对象）时建立，只在字幕中顺带一提、一笔带过的对象不建实体**（提取提示词约束 + 每轮二遍消冗：先取候选、再把候选交回模型合并近重复并剔除一笔带过项，失败时安全回退为不丢弃）。**信息动态要保留项目地址（GitHub 等仓库）、官网、下载链接等关键信息**，以 `video_summaries.links` 结构化字段保存并在动态卡片中展示。

本文件是目标范围。**实现状态（2026-10-22）**：第 1–6 条的代码已落地（迁移 0011，head），主界面已切换为精简版，高级入口隐藏但代码与数据保留；实体建立已按“只建被实质讨论的对象、剔除一笔带过项”落地，信息动态已结构化保留项目地址/官网/下载链接；第 1–6 条的**真实服务验证尚未执行**——真实 B站 关键词发现/字幕/@ 通知、真实模型视频总结/每轮汇总/实体更新、以及“每天固定钟点 → 发现 → 总结 → 汇总 → 日报”的无人值守端到端仍需在用户授权下低频烟测。
